<p align="center">
  <b>Currently in active development.</b><br>
  More information, screenshots and updates are coming soon.
</p>

---

## About

This project aims to recreate the server-side functionality required to run and explore an older version of Critical Ops — **1.30.0f1696**.

The server is being actively developed and currently includes work on core systems such as:

- Account system
- Login & authentication flow
- Player profiles
- Inventory & loadout
- Friends
- Clans
- Ranked data
- REST API
- UDP lobby / realtime networking
- Match-related systems

A lot is still being researched, implemented and improved.
